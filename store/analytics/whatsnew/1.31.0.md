**A Save that has something to save says so.** The settings page keeps one Save per section, and
every one of them used to look the same whether or not there was anything to store - permanently the
brightest thing on screen, including at the moment it meant nothing. Each now lights up, with the
words **Unsaved changes** beside it, only while what is on screen differs from what is saved.

Put a change back the way it was and both go. The question it answers is «is this different from what
is stored», not «have you touched this section» - which is what it used to answer, so ticking a box
and unticking it again left the warning behind.

Two things that follow from the same reading. Choosing an AI engine no longer reports an unsaved
change it has just saved. And a save the browser refuses now says so on the button as well as in the
notice, instead of leaving it looking idle over a section it has quietly marked as unsaved.

Nothing else in this version: the mirror, the diagrams and the exports are unchanged.
