## Search inside every query at once

The search box has a switch beside it. It reads **in: names** - view names, folders and column
names, which is what it always did - and clicking it turns it into **in: SQL**: the list then keeps
only the queries whose text contains what you typed, and each row shows the line the term is on and
how many times it appears in that query.

The first search of a session reads every `.sql` file once and says how many it read. If one will
not open it says that too, because a query nobody could read is not a query with no match.

## Fixed

- **The Lineage tab threw an error** and stayed half drawn. With it goes the «? level undefined»
  beside every entry: the sample workspace was writing its lineage and its SQL sources in a shape a
  real pull never produces, so both were wrong in the same place.
- **The export no longer carries the SQL of your query tables unless you say so.** The dialog opened
  with it ticked while these pages promised the opposite. It starts unticked now; a preference saved
  before this is cleared once, and after that your choice stands, including turning it back on.
- **The diagram is no longer handed more than it draws**, and what it is handed lives in session
  memory rather than on disk - it goes when the browser closes.
- **EXPORT** was clipped along its top edge.
- The banner shown while you are looking at the sample workspace is one line now, and says the thing
  that was missing: why **Pull** is disabled.
- **Forget** now forgets: clearing a stored API key left the plaintext in session memory until the
  browser restarted.

## Under the hood

- A response from Zoho Analytics in a shape this version does not recognise stops with the field
  named, instead of writing an empty workspace. An empty census and an unreadable answer were the
  same thing before, and for a mirror that is the worst possible confusion.
- Every paged list has one ceiling and reports hitting it.
- A stored encrypted API key records the cost it was encrypted at, so raising it later cannot make
  today's key unreadable.

Nothing changed about what is read: never the rows inside your tables, and nothing is written back
to Zoho Analytics.
