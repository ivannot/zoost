This release is about trust in the mirror: a pull either completes, or the panel says so.

## A pull is now all-or-nothing

**Pull all** builds the whole snapshot first and publishes it in one move - views, schema, SQL and
lineage together. If a stage fails, the panel keeps showing the previous complete picture instead
of a mixture of old and new. On disk, a marker records when a pull is mid-write: a mirror whose
last pull was interrupted is refused with a clear message ("run Pull all to repair") rather than
presented as if its files described one moment.

## "Not read" stopped masquerading as "does not exist"

A query table whose SQL could not be fetched simply vanished from every surface: the assistant
called it "not a query table", searches said "no matches" over queries they never opened, and the
exports skipped it without a trace. Every surface now tells the two apart - the detail pane, the
full-text search (which states its coverage: "searched 47/50 - absence is not exhaustive"), the
assistant's answers, and both exports, where the query keeps its heading with the reason and the
remedy under it.

## Two assistant tools now actually work

`search_sql` and `search_columns` had never run once: asked anything, they answered "View not
found". Both work now, and every declared tool is exercised by a test so this cannot happen
silently again. `get_relations` by name is also fixed.

## Old SQL files are cleaned up

A query table you delete or rename in Zoho Analytics no longer leaves its old .sql file in the
workspace folder forever. The pull removes what its own index no longer names, and a removal that
fails is said and retried by the next pull.

## One workspace at a time, enforced

While a pull is writing, switching workspace is refused - and everything long-running (the diagram,
the exports, the assistant) checks it still belongs to the workspace on screen before showing or
writing anything.

## Also fixed

- The diagram window owns its drawing: two windows opened close together can no longer swap
  payloads, and the copy is removed the moment the window reads it.
- A saved API key is derived at 600,000 PBKDF2 iterations (the current OWASP figure). Keys saved
  earlier keep working unchanged and are upgraded the next time you lock them.
- A markdown link in an assistant reply can no longer break out of its own attribute, and names
  from your workspace shown in the diagram status line are escaped.
