# Zoost Analytics 2.0.1

A fix release. Two things that were wrong on screen, and one that could stop the panel opening.

**«Report this problem» and «A fix may already be released» stay out of the way when there is
nothing to report.** They appeared beside messages that already explained themselves - Zoho pacing
your requests, a session it refused, an outage. Those are not defects and no release changes them,
so the panel says the plain thing and offers neither. They are still there for a failure Zoost
cannot account for, which is what they were written for.

**A refused read is reported as what it was.** The same correction as the Zoho CRM side: an answer Zoho
sends about a stale session is no longer read as Zoho pacing your requests, so the message names the
cause and the remedy rather than asking you to wait for something that will not change.

**The working folder recovers if its record is damaged.** If the small database Chrome keeps for the
folder handle lost its contents, the panel stopped at startup and there was no way back from inside
it - the only thing that could have repaired the record was the thing that had just failed. It
rebuilds what is missing now and carries on.

**Under the surface**, the code that decides which Zoho Analytics address a control opens has moved
into a file of its own, the way the Zoho CRM side has had for a while. Nothing about where a «Go to»
lands changes; it is now the same shape in both products, which is how it stays that way.
