**A query table's SQL is read correctly again.** Zoho Analytics returns the list of a query's source
tables as text rather than as a list, and Zoost read it as a list - so every query was recorded as
reading from nothing, and that empty answer was written into the local mirror. It is decoded
properly now. If a query's SQL cannot be read at all, that query is reported as unreadable instead
of being stored as empty.

**A pull that was interrupted no longer silences the next one.** Change workspace while a pull is
writing, and the following **Pull all** would re-read the whole workspace, write nothing and say
nothing - the panel looked frozen on the last progress line, and pressing again did the same. The
only way out was to reopen the side panel.

**↻ Refresh no longer writes «Ready.» over its own warning.** A workspace with a file that will not
open says so, and Refresh replaced that sentence with «Ready.» while the panel showed the views with
no tables, no columns and no relations underneath.

**Switching to a workspace whose last pull was interrupted no longer leaves the previous one on
screen.** The bar above the list went on naming the workspace you came from, offering to switch you
to the one you were already in.

**An export that could not remember your tick boxes no longer disappears.** If the browser refused
to store them the export stopped there - no file, no message. It runs with what you ticked and says
the default could not be remembered.

**Hovering a relation in the ER diagram names it the way the arrow points.** It read the two tables
in the opposite order from the arrowhead and from the card that opens on click.

**The assistant no longer sends you to Settings for export defaults**, which that page does not have -
the scope is chosen in the export dialog itself.

**⚙ is drawn rather than typed.** At the size the panel uses it, the gear character reads as a sun in
several fonts. Settings now carries a drawn mark, like the ER diagram, History and the workspace
overview.
