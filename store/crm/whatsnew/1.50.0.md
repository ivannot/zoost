**A workspace now opens on a view of itself.** The four-square button in the toolbar opens
**Workspace overview**: what is on disk for each area, when it was last read, and what to do next.
A workspace you have just created opens there by itself, with a three-step path and one highlighted
action; the sample starts at Browse, because its invented mirror is already local. Reopening a
workspace you were already using does not interrupt where you were.

**Getting started takes one click.** Pressing **Sample** when there is no working folder yet asks for
the folder, writes the sample and opens it, instead of stopping after the folder and leaving you to
find the next button. The same button then reads **Open sample** and takes you back to it.

**When Chrome drops the folder permission, the panel notices.** It always could lose it - a stored
folder handle does not survive a side panel being closed and reopened - but the panel went on
believing it had access, so it reported the local files as damaged and offered a pull that could not
have worked either. Now the folder is asked whenever a read is refused: you are told the access has
lapsed, and **one click anywhere in the panel** restores it, which is what the message says. ↻
Refresh does the same.

**And what is on screen catches up.** After access comes back, the overview, the health audit and the
assistant's context line are rebuilt. They used to keep describing the refusal, so the panel said
«nothing can be read» about a workspace it had just re-opened.

**The workspace overview button moved** out of the workspace bar and into the toolbar, beside Health,
AI and History - the controls it behaves like, since it opens a view that takes over the panel.

Smaller things: a search typed from a health row is now remembered like any other, instead of
filtering the list and being lost the moment you left the tab; the **Remove workspace** tooltip
described the state the button was in *before* the last redraw, so an offered button said it could
not act and a greyed one read as though it worked; and the module block in the detail pane is set off
from the block above it, like every other block in that pane.

**Nothing else about this version changed for you, and that is the largest part of it.** The panel's
main script was split from 7,110 lines into thirteen files with declared boundaries: same behaviour,
same files on disk, same requests to Zoho, same permissions. It is in these notes because it is most
of the diff, and because a release that says «nothing changed» about a large one should say what the
change was.
