**Three more Zoho data centres.** Zoost now works on **zoho.sa**, **zoho.uk** and **zoho.ae**, with
their sandboxes - until now it was inert there: no permission for those hosts means the panel could
not even tell it was looking at Zoho CRM. Because this adds hosts, Chrome may ask you to approve the
update before the extension runs again. Nothing else changed about what it reads.

**What Zoho says is failing.** The panel now reads the org's execution failures: which function
failed, what invoked it (workflow, button, REST API, schedule), the reason with its line number, and
how often. It appears on the function's own detail and in the workspace health audit, next to the
other things wrong with your functions. It is the one reading here that is a runtime rather than a
structure, so it carries the date it was taken - and **Pull runtime**, at the top of the health view,
re-reads only that instead of downloading the whole org again. It never re-runs a failed execution,
which would be a write, and it never reads the input of one.

**How often each function actually ran.** *Size & calls* used to show length and outbound-call counts
- proxies for what a function costs. Beside them now is the measured number: how many times Zoho ran
it in the last 24 hours, and what the org spent against its ceiling. Zoho answers with the busiest
few, so a function that is absent means "not in the top list", never "never ran" - and it reports how
*often*, not how *long*. Both limits are on screen rather than left to be discovered.

**The detail pane has two tabs.** A function's detail had grown to seven blocks stacked above the
code in a 400px panel: **Code** and **Details** now, with the code first because that is what people
open a function for. Modules got the same split - **Fields** and **Details** - and the related-list
API names, the most useful thing in there, sit at the top of the second rather than the bottom of a
column nobody reached. A picklist no longer runs off the side of the table: it shows how many values
it has and opens them in a row of its own, one boxed value at a time.

**Search finds a function by any of its names.** It matched the display name only, so looking for the
internal one found nothing.

**Go to Zoho CRM goes to Zoho CRM.** It used to open the org of the workspace you had selected, which
is the wrong org the moment you sign out of one to sign into another. It opens your Zoho CRM home now, and
beside it is a picklist of every data centre - because which org you want next is your choice, not
something the panel can deduce. Its starting point is a new **Data centre** setting.

**Also:** Settings, Help and About stay reachable when there is no Zoho CRM tab, and About no longer
opens underneath that screen; the environment guard disables *every* button that reads from Zoho
instead of the first one; the workspace list sorts by the name you actually see; **Clear** in the chat
is described for what it is, a cost control, since the whole conversation is re-sent with every
message; and a lapsed folder permission is reported in one sentence that names the control which
fixes it, instead of three that named different things.
