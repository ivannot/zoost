Nine changes, and two of them are about what leaves your machine.

## The export no longer carries your source unless you say so

The export dialog opened with **source code** already ticked, while this extension's own pages
promise the opposite: including it is meant to be a decision. It now starts unticked. If you had
turned it on before, that preference is cleared **once** - after that whatever you choose stands,
including turning it straight back on. Everything else in an export is unchanged.

## The diagram is no longer handed your code

Opening the call graph or the schema diagram wrote a copy of every Deluge function into the
browser's local storage, and left it there until the next diagram replaced it. The window never
read it: it draws names, kinds and arrows. It is given only that now, and through session storage,
which is memory - it goes when the browser closes.

## Fixed

- **EXPORT** was clipped along its top edge, everywhere the panel is drawn.
- The banner shown while you are looking at the sample workspace said the same thing three times
  and offered a button the panel already has. It is one line now, and says the thing that was
  actually missing: why **Pull** is disabled.
- **Forget** now forgets. Clearing a stored API key left the plaintext in the browser's session
  memory until you restarted it.

## Under the hood

- A Zoho response that arrives in a shape this version does not recognise now stops with the
  missing field named, instead of being mirrored as an area with nothing in it. «Zoho said none»,
  «Zoho refused» and «that is not the answer I know how to read» are three different things.
- Every paged list has one ceiling and reports hitting it, the function list included: a list that
  stopped early no longer looks like a complete census.
- A stored encrypted API key now records the cost it was encrypted at, so raising that cost in a
  future version cannot make today's key unreadable.
- The save notice the Zoho page sends the panel is narrowed to this window and its id checked.

Nothing else changed about what is read, what is written, or where anything goes: no server, no
account, no telemetry, and nothing written back to Zoho.
