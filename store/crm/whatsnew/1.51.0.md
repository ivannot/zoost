**A pull now says what it is doing.** On a large org some stages used to sit silent for minutes -
the files inside a compiled function, the fields of each module, the detail of every action - and a
panel that says nothing is indistinguishable from a panel that has stopped. Each of those stages now
reports its subject and its progress on the status line: «Modules… 7 of 20», «Task details… 120 of
430».

**Two things that were reported from a real org are fixed.**

A Zoho user without administrator rights who pulled **only the Connections tab** was shown a message
about security tokens and browser cookies - alarming, and wrong. It says the true thing again: this
Zoho user does not have access to that area. The tab stays, and a later pull asks Zoho once more.

Downloading a single Java, Python or Node function left the status bar spinning on «Files for X…»
after the download had finished, or after it had failed. It now goes back to what it said before.

**A deleted compiled function takes its files with it.** When a Java, Python or Node function is
deleted in Zoho, the next pull removed its manifest and left its source files on disk - and once the
manifest was gone nothing could find them again, while the panel reported them as removed. Deluge
functions were never affected. If you have such leftovers from an earlier version, they are files in
`functions/<namespace>/<name>.files/` whose function no longer exists in Zoho; this version does not
hunt for them, it stops making them.

**A function deleted while a pull is running is named as missing, not as an error.** It used to
arrive as an internal message about a malformed reply, and cost a pointless retry.

**Nothing else changed for you, and that is most of the work.** The panel's main script was split
into eleven modules with declared boundaries, a pull now has an explicit lifecycle, and file removals
go through a plan that refuses to delete anything after an incomplete reading. Same behaviour, same
files on disk, same requests to Zoho, same permissions. It is here because it is most of the change,
and because a release that says «nothing changed» about a large one should say what the change was.

**⚙ is drawn rather than typed.** At the size the panel uses it, the gear character reads as a sun in
several fonts. Settings now carries a drawn mark, like Wiring, History and the workspace overview.
