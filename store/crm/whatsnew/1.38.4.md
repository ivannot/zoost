**If you already have a working folder, press Pull all once.** The files are organised differently:
one folder per kind (`functions/`, `modules/`, `workflows/`…), layouts now live inside `modules/`, and
the leading underscore is gone. A folder still in the old shape is recognised, named, and the panel
says which folders to delete. Nothing is touched until you ask.

**Try everything without connecting anything.** `+ Sample` writes a workspace of invented data into
your working folder — a couple of hundred Deluge functions with real call chains, modules with
lookups, workflows, schedules and connections. It opens with no Zoho tab and no account: the tree, the
diagrams, the audit and the exports all work on it. It is generated, never fetched, everything that
would talk to Zoho is disabled for it, and you delete it by deleting the folder.

**The diagram window is a different product.** Functions now get the boxed, focusable, printable
diagram that only modules had. The call graph closes: workflows, schedules and connections are nodes,
so you can see what *starts* the code and what it *reaches* — and a connection nothing uses becomes
visible. Filters rebuild the drawing instead of hiding pieces, so switching a category off genuinely
makes a large graph readable; the focus belongs to the window and applies to every view; Relations
catalogues calls the way it catalogued related lists; and the layout engine was rewritten — a large
org is drawn in half a second instead of six, and shows its structure rather than a circle.

**Your API key can be locked with a passphrase.** Optional, off by default. With it the key is
encrypted at rest (PBKDF2-SHA256 → AES-GCM-256) and asked for once per browser session. There is no
recovery, and that is stated where the choice is made.

**Workflows: what does not fire straight away.** Which rules have time-based actions, with the delay,
and when each rule last ran.

**A module Zoho refuses to describe now says so.** It used to appear with zero fields and zero
layouts, indistinguishable from one nobody had pulled, under advice that could not work. It now
carries the reason and the date it was given, in Zoho's own words, and nothing downstream states a
count for something that was never read.

**The assistant** knows what you have selected whatever kind of thing it is, not only when it is a
function, and it knows what the extension itself does — so "how do I export this?" is answered in the
panel.

**Also:** links that have nothing to do with Zoho open in a window instead of moving the tab under
you; leaving a workspace drops everything that belonged to it, the conversation included; an empty
list names *the* reason it is empty rather than *a* reason, and one click anywhere in the panel
restores the folder permission; the manifest declares its Content Security Policy explicitly; the icon
was redrawn.
