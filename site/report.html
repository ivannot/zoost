There is nothing to report here. This page shows a report that a Zoost panel prepared - open it from the panel's Report this problem button. If you came here to report something by hand, open an issue or write to ivan@zoost.it.

What will be sent

Read it. The panel has already taken out ids, addresses, names in quotes and the URLs it saw; what remains should name no part of your business.

It is locked, and that is on purpose. This is the trace: what fixes the problem is that it is exactly what your browser produced. If you delete or change any of it, the report is still welcome - but it is no longer evidence, so it travels marked as altered, because a diagnosis built on a trace that was quietly edited is worse than no diagnosis.

Before you send

  • This becomes a public issue on the Zoost repository, under Ivan's account, visible to anyone, indexed, and permanent.
  • If what you are reporting is a security problem, do not send it here. Write to ivan@zoost.it, which is private.
  • There is no guaranteed response time. Zoost is maintained in spare time.
